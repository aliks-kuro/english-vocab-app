# VocabMaster 🗡️

---

## みなさんへ

英単語の意味が分からなかったとき、その場で調べて「なるほど！」と理解して——そして数時間後にはすっかり忘れている。そんな経験、ありませんか？

単語帳を作っても眺めるだけで身につかない。アプリで一問一答をこなしても、なんとなく作業感があって続かない。

「覚えた気」はするのに、いざ使おうとすると出てこない。

英語学習でよく言われる「インプットだけでは定着しない」という問題の核心は、**アウトプットの機会が少ないこと**と**繰り返しが苦痛なこと**にあると思っています。

**VocabMaster** はそこに向き合ったアプリです。  
単語を "ゲームとして楽しみながらアウトプットする" ことで、自然と繰り返し触れる環境を作りました。スコアやコンボの緊張感、モンスターが迫ってくる演出が、記憶への引っかかりになります。覚えた瞬間の達成感が、次にまた開くモチベーションになります。

勉強している感覚なく、でも確実に頭に入っていく——そんな学習体験を目指しています。

---

## こんな人におすすめ

- 単語を覚えてもすぐ忘れてしまう
- 勉強が続かない・飽きやすい

## 機能一覧

### 📚 単語帳管理
- 英単語を検索してマイリストに追加（Free Dictionary API + MyMemory 翻訳）
- 英語・日本語訳・品詞・ハッシュタグを入力して手動追加も可能
- 「覚えた」フラグで進捗管理
- フィルター機能：自作単語のみ・タグで絞り込み
- インライン編集で定義を自由に修正

### 🎮 3種類のゲーム

| # | モード | 内容 |
|---|---|---|
| 🔤 | **アナグラム** | 画面を飛び回る文字タイルをタップして正しいスペルを完成させる |
| 🚂 | **レールゲーム** | トロッコが分岐する前に正しい意味の選択肢へ導く |
| 🗡️ | **ダンジョン・タイピング** | 迫りくるモンスターに向かって英単語をタイピングして撃破 |

### ⚔️ ダンジョン・タイピングのこだわり
- **7段階の難易度**：スライム（中学基礎）→ 魔王（専門用語・難読）
- **緊迫感のある演出**：残り時間が減るほどモンスターが画面に近づいてくる
- **コンボボーナス**：連続正解でスコア倍率アップ（最大 ×3.0）
- **リザルト画面**：クリア・全滅後に正解・不正解の問題を一覧で振り返り

## 技術スタック

| カテゴリ | 採用技術 |
|---|---|
| フレームワーク | React 19 + TypeScript |
| ビルドツール | Vite |
| スタイリング | Tailwind CSS |
| アニメーション | Framer Motion |
| 状態管理 | Zustand（localStorage 永続化） |
| ゲーム描画 | Canvas 2D API（requestAnimationFrame） |
| ルーティング | React Router v7 |
| 単語データ | [Free Dictionary API](https://dictionaryapi.dev/) + [MyMemory](https://mymemory.translated.net) |
| デプロイ | Vercel |

## セットアップ

```bash
git clone https://github.com/aliks-kuro/english-vocab-app.git
cd english-vocab-app
npm install
npm run dev
```

開発サーバーが `http://localhost:5173` で起動します。

```bash
npm run build    # 本番ビルド
npm run preview  # ビルド後のプレビュー
```

### 環境変数（Vercel デプロイ時）

| キー | 説明 |
|---|---|
| `VITE_ACCESS_PASSWORD` | アクセス制限用パスワード（未設定の場合は制限なし） |
